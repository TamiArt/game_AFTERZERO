Целевая аудитория

Основная аудитория:

15–50 лет.

Визуальный стиль не должен выглядеть как детская мобильная игра.

Нужно создать ощущение:

премиального современного digital-продукта + игры + интерактивного мира.

Игра должна одинаково хорошо восприниматься:

подростками;
молодыми взрослыми;
взрослыми пользователями 30–50 лет.

Не использовать чрезмерно детские персонажи, кислотный интерфейс, дешёвые градиенты и типичный стиль «тапалок».

3. Основная концепция мира

После первого запуска игрок видит небольшой пустой остров.

На нём:

небольшой участок земли;
один заброшенный объект;
несколько природных объектов;
неизвестная область;
один загадочный объект/портал;
персонаж игрока.

Игрок начинает буквально с нуля.

Первое сообщение:

«Здесь ничего нет. Что появится первым — решаешь ты.»

Далее игрок проходит короткое обучение.

6. Игровой мир

Использовать 2D/2.5D изометрическую графику.

Не делать полноценный 3D.

Причины:

быстрая загрузка;
высокая производительность на телефонах;
возможность работать внутри Telegram;
проще создавать большое количество контента;
проще масштабировать проект;
ниже стоимость разработки.

Карта должна состоять из отдельных участков/тайлов.

Игрок сможет:

перемещать камеру;
приближать/отдалять;
выбирать объекты;
строить;
взаимодействовать с объектами;
открывать новые территории.
7. Визуальный стиль

Это один из важнейших пунктов проекта.

Игра должна выглядеть как дорогой современный продукт 2026 года.

Не использовать:

типичный мультяшный стиль;
дешёвую мобильную графику;
чрезмерно детские персонажи;
стандартные fantasy-assets;
визуальный шум;
огромное количество текста;
старомодный интерфейс.

Предпочтительный стиль:

Premium stylized 2.5D

Сочетание:

изометрических диорам;
современных игровых интерфейсов;
кинематографического света;
мягких теней;
стеклянных/полупрозрачных UI-элементов;
необычных материалов;
глубины;
атмосферных эффектов;
живой природы;
футуристических деталей.

Визуальная философия:

«Если Apple, современная игра и интерактивная арт-инсталляция создали бы один мир».

Цветовая палитра должна быть современной, но не кислотной.

8. Первый игровой туториал

После первого запуска не показывать длинную инструкцию.

Пользователь должен пройти обучение непосредственно через игру.

Игрок нажимает.

ДОМ

🪨 5 камня

Игрок строит дом.

Получает XP.

Шаг 4

Открывается новая территория.

Шаг 5

Появляется загадочный объект.

«Что это?»

Игрок нажимает.

Появляется:

«Исследование доступно на 3 уровне.»

Так формируется интерес к дальнейшему прохождению.

Добавить систему событий.

Для MVP минимум 20 событий.

Типы:

портал;

События должны генерироваться сервером.

Часть событий может быть временной.

Например:

«Сегодня на острове появился неизвестный портал.»

После завершения события результат сохраняется в мире игрока.

14. Питомец

На 5 уровне открывается система питомцев.

Для MVP:

5 типов питомцев;
имя;
уровень;
опыт;
состояние;
несколько визуальных реакций.

Питомец должен физически находиться на карте.

Например:

игрок идёт по острову → питомец идёт за ним.

Питомец должен создавать эмоциональную привязанность, но не должен наказывать игрока за отсутствие в игре.

Критерии готовности MVP

Разработчик не должен считать проект готовым просто потому, что «страницы работают».

MVP считается готовым, если:

игра запускается внутри Telegram;
игра работает на мобильном телефоне;
прогресс сохраняется после закрытия приложения;
пользователь может создать и развивать свой мир;
строительство работает;
ресурсы корректно начисляются и списываются;
уровни работают;
события работают;
питомец работает;
коллекция работает;
другой игрок может посетить мир;
социальные действия работают;
рейтинг работает;
нет возможности изменить ресурсы через клиент;
есть базовая аналитика;
магазин существует визуально, но реальные платежи отключены;
приложение не требует платной подписки для тестирования.
Главная цель первой версии

Не сделать сразу огромную игру.

Нужно создать маленький, но настолько красивый и живой мир, чтобы после первого запуска человеку захотелось открыть его снова завтра.
